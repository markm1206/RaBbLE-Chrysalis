RaBbLE-Server

origin: markm1206/RaBbLE-Xperimental · archive: archive/raBbLE-server

The first agentic intelligence API — a FastAPI microservice harness for routing conversations, managing multi-step workflows, and orchestrating LLM providers. Built before sCoRE, before the Collective. The patterns here — stateless services, multi-provider routing, harness/service separation — directly informed the sCoRE architecture.

Archive · source view — This project is a Python server application. It cannot run in the browser. The architecture and source code are documented here as a reference artifact.
architecture
RaBbLE-Server — harness around stateless microservices HARNESS LAYER ← deployment, secrets, env └─ harness/ deploy.sh ← Railway TUI deploy local.sh ← start locally env_gen.sh ← .secrets → .env railway_ctl.sh ← manage Railway project SERVICE LAYER ← application logic only └─ services/intelligence/ main.py ← FastAPI app, all routes llm.py ← Groq + OpenRouter routing agents.py ← RaBbLE persona, workflows auth.py ← JWT + API key auth workflows.py ← agentic state machine rate_limit.py ← sliding-window limiter audit.py ← append-only JSONL log
intelligence service modules
LLM Router
llm.py

Multi-provider LLM client — Groq and OpenRouter backends, unified interface. The prototype for sCoRE's provider abstraction.

Persona Engine
agents.py

RaBbLE persona and agentic workflow definitions. The first attempt at encoding RaBbLE's character in code.

Auth
auth.py · auth_routes.py

JWT + API key authentication. Register / token endpoints. Rate limiting via sliding-window limiter.

Workflow Engine
workflows.py

Agentic state machine — multi-step conversation workflows. First concept of persistent agent state.

Audit Log
audit.py

Append-only JSONL event log — every action recorded. The observability primitive sCoRE inherited.

Deployment
railway.json · Procfile

Railway-native deployment config. Fully self-contained — any service independently deployable.
